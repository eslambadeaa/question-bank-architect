# منظومة بنوك الأسئلة والمناهج التفاعلية (Question Bank & Syllabus Architect)

أداة ذكية متخصصة واحترافية لتحليل المراجع والأدلة الفنية والأكاديمية، واستخراج الجداول الزمنية وفهارس المناهج، وتوليد بنوك أسئلة معيارية متكاملة تتوافق بنسبة 100% مع أنظمة إدارة التعلم الإلكتروني الحديثة (LMS).

---

## 1. 📌 نبذة عن التطبيق
تطبيق متقدم ومخصص لإنشاء بنوك الأسئلة والمناهج التفاعلية من المراجع والوثائق التخصصية (PDF / Word DOCX). صُمم النظام بهندسة أمنية صارمة تضمن **أقصى درجات السرية والخصوصية التامة**؛ حيث تجري معالجة الوثائق واستخراج النصوص وبناء مصنفات العمل محلياً على جهاز المستخدم (سواء كان حاسوباً شخصياً أو هاتفاً محمولاً) دون تخزين أو حفظ أو نشر البيانات والملفات عبر أي خوادم خارجية وسيطة.

---

## 2. 🎯 التوافق مع أنظمة إدارة التعلم (LMS Compliance)
- **توافق تام 100%:** مخرجات النظام متطابقة بالكامل مع معايير بنوك الأسئلة المعتمدة وجاهزة فوراً للاستيراد المباشر إلى مختلف منصات إدارة التعلم والتقييم الإلكتروني (LMS).
- **قاعدة السطر الفردي الصارمة (Strict Single-Row Rule):** كل سطر في الفهرس يمثل محاضرة/درساً فردياً مستقلاً تماماً، ويُمنع منعاً باتاً دمج المحاضرات أو كتابة نطاقات (مثل "محاضرات 1-2").
- **المعادلة القياسية الموحدة (1 : 2 : 25):**
  - **1 محاضرة فردية** لكل سطر.
  - **2 ساعة تدريسية** زوجية معتمدة لكل سطر.
  - **25 سؤالاً بالضبط** لكل سطر (15 سؤال اختيار من متعدد باربعة خيارات + 10 أسئلة صواب وخطأ True/False).
- **التدرج الوزني المعتمد للأقسام (نسبة 1 : 2 : 2):**
  - **القسم الإعدادي:** 28 محاضرة | 56 ساعة تدريسية | 700 سؤال.
  - **القسم المتوسط:** 56 محاضرة | 112 ساعة تدريسية | 1,400 سؤال.
  - **القسم النهائي:** 40 محاضرة | 80 ساعة تدريسية | 1,000 سؤال.

## 4. 🚀 دليل وطريقة الاستخدام

### أ) الحصول على مفتاح الواجهة البرمجية (Google Gemini API Key)
1. انتقل إلى منصة [Google AI Studio](https://aistudio.google.com/).
2. سجّل الدخول بحساب Google الخاص بك، ثم اضغط على **"Get API key"**.
3. أنشئ مفتاحاً جديداً بالضغط على **"Create API key"** وانسخ المفتاح.
4. في شريط إعدادات التطبيق الجانبي، الصق المفتاح في خانة `مفتاح Google Gemini API`.
5. اضغط على زر **"💾 حفظ المفتاح"** ليتم حفظه بأمان على جهازك للاستخدامات المستقبلية.

### ب) تخصيص صفحات محددة لكل قسم
- يدعم التطبيق تحديد نطاقات صفحات مرنة ومستقلة لكل قسم (القسم الإعدادي، المتوسط، النهائي):
  - **كامل المرجع (All):** قراءة المرجع من أوله لآخره بدقة 100%.
  - **أول N صفحة:** مثل كتابة `20` لقراءة أول عشرين صفحة فقط.
  - **نطاق صفحات محدد:** مثل `1-50` أو `20-80` لقسم معين.
  - **صفحات متفرقة:** مثل `1, 3, 5, 10-15` لاختيار فصول أو موضوعات نوعية بعينها.

### ج) دمج مراجع متعددة في بنك أسئلة متكامل
- يمكنك رفع مراجع متعددة في نفس الوقت، وتوزيع كل مرجع على القسم المخصص له، أو تخصيص مرجع مختلف لكل قسم.
- يستنتج النظام تلقائياً اسم المنظومة/المعدة الفنية لكل قسم بناءً على المرجع الخاص به، مع إمكانية تعديل الاسم يدوياً.
- خيار تفعيل/تعطيل تكرار وتثبيت الأسئلة مستقل لكل قسم.

## 5. 🔒 تعليمات الأمان والسرية
- **معالجة محلية بالكامل:** يتم تحليل مستندات Word وPDF محلياً عبر مكتبات معالجة البيانات، ولا يتم رفع ملفاتك إلى أي سحابة تخزين.
- **أمان المفاتيح:** مفتاح الـ API يُحفظ محلياً فقط في ملف إعدادات داخلي على جهازك الشخصي ولا يتم إرساله لأي جهة سوى Google Cloud API مباشرة عبر اتصال مُشفر (HTTPS).
- **إمكانية الحذف الفوري:** يمكنك بنقرة واحدة من الواجهة الضغط على **"🗑️ حذف المحفوظ"** لمسح المفتاح وسجلات الجلسة نهائياً من الذاكرة وجهازك.

## 💻 التثبيت والتشغيل المحلي (Local Setup)

```bash
# 1. استنساخ المستودع
git clone https://github.com/eslambadeaa/question-bank-architect.git
cd question-bank-architect

# 2. إنشاء بيئة افتراضية (اختياري ولكن موصى به)
python -m venv venv
venv\Scripts\activate  # على ويندوز
# source venv/bin/activate  # على لينكس/ماك

# 3. تثبيت المتطلبات
pip install -r requirements.txt

# 4. تشغيل التطبيق
streamlit run app.py
```

يفتح التطبيق تلقائياً في المتصفح على العنوان: `http://localhost:8501`.
